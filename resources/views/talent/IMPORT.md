
Explication pédagogique + Engagement éthique
💡 Les Phrases d’explications pédagogiques :
Avant de commencer la création du CV anonyme, trois pop-ups ou infobox s’affichent pour expliquer la démarche, qu’il s’agisse d’un import ou d’une saisie manuelle :

Explication des champs grisés :
“Chez YABARA, nous croyons en un recrutement fondé sur les compétences. Vos informations personnelles sont masquées pour garantir un traitement équitable par tous les recruteurs.”
Rassurer sur la confidentialité :
“Vos informations personnelles (nom, email, téléphone) sont automatiquement masquées pour prévenir toute forme de biais ou de discrimination, seules vos compétences et expériences parlent pour vous.”
Souligner l’impact positif pour l’équité :
“🤝 Chaque CV anonyme sur YABARA est un pas vers un recrutement sans préjugés, sans favoritisme, sans barrières. Merci d’y participer !”


🎯 Objectif pour le talent :
Rendre la création du CV anonyme simple, claire et rassurante, que le talent choisisse d’importer un CV ou de le remplir manuellement.

🔑 1. Deux options : Import ou Saisie Manuelle
💡 Option 1 : Import du CV :
Le talent peut importer un CV (PDF/Word) via une interface intuitive. Une fois importé, il visualise son CV et peut le modifier si nécessaire.

💡 Option 2 : Saisie manuelle :
Le talent peut choisir de ne pas importer de CV et remplir directement un formulaire vierge pour créer son CV anonyme, en ajoutant :

Expériences,
Formations,
Compétences,
Langues.

✅ Avantages :

Flexibilité : Le talent choisit la méthode qui lui convient (import pour gain de temps ou saisie manuelle pour contrôle total).
Simplicité : Pas de traitement automatique, donc pas de confusion sur les données extraites.
Équité : Les informations sensibles sont masquées dans les deux cas.


🎨 2. Interface en 2 colonnes claire et rassurante
💡 Proposition :
L’interface est divisée en deux colonnes, adaptée selon l’option choisie :

Colonne gauche :

Si import : Affiche le CV original (PDF/Word, non modifiable) pour référence, via un visualiseur (ex. : PDF.js).
Si saisie manuelle : Cette colonne est vide ou affiche un message incitant à remplir le formulaire à droite.


Colonne droite : Formulaire pour créer le CV anonyme YABARA, avec des champs pour saisir ou éditer :

Expériences,
Formations,
Compétences,
Langues.


Les champs sensibles (nom, prénom, email, téléphone…) sont grisés, marqués comme inactifs avec une pastille "anonymisé 🔒".
Design : Couleurs douces (ex. : vert pastel pour validation, gris clair pour champs grisés) et icônes de cadenas (ex. : Font Awesome) pour indiquer les informations masquées.


🧩 3. Builder de CV anonyme modulaire
💡 Builder CV :
L’interface utilise un système de “builder par blocs” (inspiré de Notion ou Canva) pour ajouter facilement des sections, que ce soit après un import ou en saisie manuelle :

Ajouter une expérience 📌
Ajouter une formation 🎓
Ajouter une compétence 🧠
Ajouter une langue 🌐

Chaque bloc est intuitif, réorganisable (drag-and-drop) et supprimable, offrant une personnalisation simple et claire.

🔄 4. Prévisualisation live du CV anonyme
💡 Prévisualisation CV :

Une section (en haut ou à droite) affiche une prévisualisation en temps réel du CV anonyme, tel qu’il sera vu par les recruteurs.
Chaque modification dans le formulaire (ajout, édition ou suppression de blocs) est immédiatement reflétée.
Score de complétion : Une barre de progression indique l’avancement (ex. : 25% par section remplie : expériences, formations, compétences, langues).
Auto-sauvegarde : Les modifications sont enregistrées automatiquement (via localStorage ou backend), sans besoin de cliquer sur “enregistrer”.


✍️ Résumé de l'expérience d’importation ou saisie manuelle du CV & création du CV anonyme :

Le talent choisit entre importer un CV (PDF/Word) ou remplir manuellement un formulaire vierge.
Si import, le CV original s’affiche à gauche pour référence ; si saisie manuelle, le talent commence directement dans le formulaire.
L’interface builder modulaire permet d’ajouter, éditer ou supprimer des blocs (expériences, formations, etc.).
Une prévisualisation en temps réel montre le rendu final du CV anonyme.
Les champs sensibles (nom, contact…) sont grisés et expliqués via des pop-ups pédagogiques.
Un score de complétion motive le talent à finaliser l’étape.
